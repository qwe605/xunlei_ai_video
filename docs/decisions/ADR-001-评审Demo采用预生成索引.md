# ADR-001：评审 Demo 采用预生成索引

## 状态

已接受

## 背景

长视频转写、向量化和多模态理解需要模型权重、算力和较长处理时间。若评审现场执行完整
链路，网络、GPU、API 配额或模型下载中的任何一项都可能阻断产品体验。

## 决策

公开 Demo 使用经过 schema 校验的预生成索引，并在浏览器中真实执行搜索、结果解释、
问答证据约束和视频时间跳转。真实 AI 处理作为独立离线样例接入，不成为评审链接的
运行依赖。

## 后果

- 评委无需账号、GPU 和 API Key 即可完成完整体验。
- Demo 必须公开说明数据经过预生成，不能宣称现场完成长视频推理。
- 前端通过稳定数据契约与未来 FastAPI/处理管线解耦。
