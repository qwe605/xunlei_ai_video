# ADR-002：视频问答必须引用可跳转证据

## 状态

已接受

## 背景

通用大模型可能使用自身知识回答问题，但用户需要的是“这段视频里是否讲过，以及在哪
一分钟”。没有视频依据的流畅回答会损害产品可信度。

## 决策

每个肯定回答必须包含 1 至 3 个字幕或章节证据，证据必须具有视频 ID、起止时间、文本
和置信度。跳转按钮只能由证据结构生成，不能从自然语言回答中猜测时间。

没有检索到证据时，统一返回“当前视频中没有找到相关内容”。

## 后果

- 回答可核验、可跳转，也便于用户反馈。
- 部分模型知道但视频未提及的问题会被拒答，这是产品边界而不是能力缺陷。
- 模型输出必须通过 schema 校验后才能进入界面。
