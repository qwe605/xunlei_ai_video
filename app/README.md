# 迅雷 AI 片库 Demo

这是“迅雷 AI 片库”的可交互产品 Demo。它面向拥有大量云盘视频的用户，把传统文件名
搜索升级为基于文件信息、摘要、字幕和章节的自然语言检索，并把搜索结果直接连接到
播放器时间片段。

## 当前可体验功能

- 展示 4 个已预先完成 AI 整理、带真实音轨的样例视频，其中 3 个中文、1 个英文。
- 从本机导入 MP4/WebM，真实读取时长、分辨率并抽帧生成封面。
- 使用 Blob URL 在当前会话直接播放刚导入的视频，不替换成内置素材。
- 重新导入同名内置中文素材时只复用字幕、摘要与章节，仍保留用户文件的 Blob 播放地址。
- 校验 BTIH 磁力链接并调用系统迅雷客户端；云盘自动转存等待官方开放接口。
- “我的片库”支持本地注册、登录、退出，密码经 PBKDF2-SHA256 派生后保存；在公网 HTTP IP
  无法使用 Web Crypto 时，会自动切换到同算法的软件实现，既有账号摘要保持兼容。
- 本地导入后自动进入 AI 整理队列，展示阶段、进度、阻塞原因和重试操作。
- 导入时可选择“快速”或“精准”：快速使用 Paraformer-zh，精准真实调用 faster-whisper
  large-v3；队列会显示选择，不会静默降级。
- 本地 FastAPI 服务对中文音轨运行 FunASR Paraformer-zh 生成 WebVTT 字幕，再调用
  MiniMax-M3 生成简体中文摘要、关键词、语义章节并保守修正常见术语。
- 在传统文件名搜索与 AI 推荐之间切换。
- 使用自然语言搜索“讲 Python 名字由来的视频”。
- 查看每个 AI 搜索结果的匹配原因、相关章节和置信度。
- 在详情页查看摘要、标签、媒体信息和智能章节。
- 从 `02:04` 的“Python 名字的由来”章节直接进入播放器。
- 向当前视频提问，并从回答跳转到 `11:28` 的保留字段落。
- 在播放器中切换字幕，并通过同步字幕列表跳转到对应画面。
- 中文字幕按标点和连接词切分，但画面不显示标点；单条最多 20 字、约 4.5 秒。
- 内置中文样例使用独立 Ground Truth 只校准时间轴，保留 AI 文本、真实停顿和原有字幕分段。
- 查看中文无字幕视频经 `FunASR Paraformer-zh + MiniMax-M3` 生成并校对的 AI 字幕。
- 对视频中不存在的问题明确拒答，不使用模型常识补充。
- 覆盖排队、处理中、完成和等待 AI 服务状态，不无限显示处理中。

## 本地运行

Windows PowerShell 环境使用 `npm.cmd`，避免本机执行策略拦截 `npm.ps1`。

首次运行和日常启动统一使用：

```powershell
cd E:\xunlei
.\tools\start-local-demo.ps1
```

脚本会首次创建 `backend\.venv` 并安装本地 AI 依赖，同时启动 `127.0.0.1:8000`
分析服务和 Vite。首次整理中文视频时会下载 FunASR 中文模型，之后复用本机缓存。
MiniMax 配置放在被 Git 忽略的 `backend\.env.local`，字段参考 `backend\.env.example`。

生产构建与预览：

```powershell
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1
```

```powershell
npm.cmd run lint
npm.cmd run test

npm.cmd run test:e2e

```

视觉回归快照属于默认 E2E 门禁。评委验收截图是独立任务，运行 `npm.cmd run capture:qa`
后写入 `E:\xunlei\output\qa\`，不会在普通验证中覆盖。

完整工程验证从项目根目录运行：

```powershell

```

## 数据真实性说明

在线/本地 Demo 使用预生成数据，目的是保证评委无需 GPU、模型下载或 API Key 即可稳定
体验完整产品闭环。搜索排序、证据约束、无依据拒答和真实视频时间跳转均由前端实际执行，
不是录屏贴图。

唯一的英文教程来自 Wikimedia Commons；三段中文样例来自用户提供的本地素材，每段截取
135 秒用于产品演示。中文公开字幕由纯音频 FunASR Paraformer-zh 生成，MiniMax-M3 在同一
请求中完成简体中文内容整理和保守校对。视频中的内嵌字幕不参与文本生成，仅作为离线 CER
评测与内置样例时间轴校准的标准答案；校准过程不会把内嵌字幕文字写入产品字幕。
当前公开排版版字符错误率为 14.30%，虽然“正｜因如此”“最后一只｜烛龙”等断词已消除，
识别准确率仍需通过更强中文 ASR 与领域热词继续优化。所有内置视频的字幕、摘要和章节均已
预生成，打开片库时不会排队。评测记录位于 `output/funasr-eval/`。

## 导入能力边界

本地导入是完整可运行能力：文件不会上传到 Demo 服务器，刷新页面后临时记录会清除。
磁力链接可通过系统协议交给已安装的迅雷客户端，下载完成后再选择本地文件导入。
由于迅雷开放平台目前没有公开个人云盘离线任务的网页 API，Demo 不模拟账号授权、
云端转存进度或成功结果；生产接入需要迅雷内部提供鉴权、创建任务、查询状态和选择
视频文件等接口。

## 账号边界

Demo 本地账号只用于证明注册、登录、退出和会话状态，数据保存在当前浏览器。公开可查的
迅雷帐号开放平台仍要求开发者登记应用获取 AppID，且没有公开个人云盘文件列表、离线任务
和播放地址权限。为避免让评委误以为登录即可读取云盘，Demo 不展示迅雷账号关联入口；
正式产品应直接复用迅雷内部登录态和文件权限。

## AI 整理队列

队列会真实推进任务阶段。所有内置素材直接复用校验后的预生成字幕、摘要和章节。其他本地
MP4/WebM 会提交到仅监听 `127.0.0.1` 的本地服务；快速模式使用 Paraformer-zh，精准模式
使用 faster-whisper large-v3，并用词级时间戳改善字幕切分同步。视频使用随机临时文件，任务结束后立即删除；
字幕文本会发送给 MiniMax-M3 做内容理解，API Key 只保存在后端。服务离线、视频无音轨、
没有清晰人声或模型失败时会显示具体原因并允许重试。

## 磁力链接

“在迅雷中打开”通过本地后端调用 Windows 已注册的 `magnet:` 协议，不再依赖浏览器
是否允许外部协议。如果未安装迅雷或协议未注册，界面会显示原因并提供“复制链接”回退。
